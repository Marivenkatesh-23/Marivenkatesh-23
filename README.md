### 💻 Featured Hardware & VLSI Projects

> **[RTL-to-GDSII: Telemetry-Integrated AXI Bridge for CDC](https://github.com/Marivenkatesh-23)**
> * **Role:** Complete Physical Design Flow (Cadence Genus/Innovus).
> * **Impact:** Architected a 32-bit AXI4 bridge using asynchronous FIFOs on a 90nm node. Synthesized an ultra-low-power netlist (~1.03 mW) and achieved zero setup/hold violations (+17.156 ns WNS) for a tape-out ready GDSII stream.

> **[FPGA Edge AI: Siren Detection Accelerator](https://github.com/Marivenkatesh-23)**
> * **Role:** AI Optimization & Vitis HLS IP Design.
> * **Impact:** Fully quantized a 1D-CNN to INT8 and engineered a "BRAM Shelf" in Vitis HLS. Deployed on a Zynq-7020 SoC, achieving 31.00 µs inference latency at <0.07 W programmable logic power.

> **[90nm Custom IC: TSPC D-Flip Flop](https://github.com/Marivenkatesh-23)**
> * **Role:** Transistor-Level Analog Design (Cadence Virtuoso).
> * **Impact:** Validated Clock-to-Q robustness across 36 extreme PVT corners, achieving 250 MHz operation at just 1.242 µW. Delivered a 100% DRC/LVS clean layout with Quantus QRC parasitic extraction.

> **[UrbanSound8K Pattern Recognition Pipeline](https://github.com/Marivenkatesh-23)**
> * **Role:** Data Engine Architecture & SVM Model Development.
> * **Impact:** Engineered a feature extraction pipeline pulling 65+ spectral features. Developed an RBF-kernel SVM achieving 86.57% accuracy, proving feature engineering superiority over raw deep learning for this dataset.
